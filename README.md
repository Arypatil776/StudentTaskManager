# Student Task Manager - Jenkins Assignment 3

Mini Node.js web application created for DOSSL Assignment 3.

## Project structure

- `public/index.html` - webpage
- `public/style.css` - styling
- `public/script.js` - task functionality
- `app.js` - Node.js server
- `build.js` - Jenkins build validation script
- `package.json` - npm configuration

## Local build

```bash
npm install
npm run build
```

Expected output:

```text
Starting application build validation...
Application files validated successfully.
Build completed successfully.
```

## Run the application

```bash
npm start
```

Then open:

http://localhost:3000
